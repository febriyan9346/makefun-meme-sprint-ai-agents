A two-panel meme about an AI agent shipping games: ask for a simple game of
Pong, and four seconds later the agent ships a battle pass, $4.99 skins, DLC
pack 12, a boss fight, a prestige mode — and a bug it labelled "feature".
SHIPPED IT. The program draws the meme itself (stdlib only — a 5x7 bitmap
font, hand-rolled shapes, and a small PNG encoder) and writes it to
/output/entry.png (1024x1024 PNG).

## Run it

```sh
python3 main.py
```
